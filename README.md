# ASOUGA — عالم اسوقة ♡

تجربة عيد ميلاد عربية RTL، مبنية بـ Next.js وTypeScript وCSS وCanvas. لا تحتوي على صور؛ المشاهد والزخارف مرسومة في الواجهة. النصوص الأساسية في `src/data/content.ts`.

## التشغيل

```sh
npm install
npm run dev
```

ثم افتحي http://localhost:3000. للإنتاج استخدمي `npm run build` ثم `npm start`.

## المحتوى والخصوصية

- تقدم الألعاب يُحفظ في `localStorage` على الجهاز الحالي.
- لوحة الإعدادات تتيح معاينة نص مخصص مؤقتاً، بينما المحتوى الرسمي يُعدّل من ملف البيانات.
- لوحة إدارة محمية بكلمة مرور وتخزين مركزي لم تُفعّل بعد؛ يلزم إعداد خادم ومخزن بيانات قبل اعتبارها لوحة إدارة آمنة أو مشاركة التعديلات بين الأجهزة.
- المشاهد مصممة للعمل باللمس ولوحة المفاتيح، مع احترام `prefers-reduced-motion`.
- جميع الذكريات قابلة للإضافة من ملف البيانات ولا تُعرض ذكريات شخصية مختلقة.

## التخصيص

حرري `src/data/content.ts` لإضافة أقسام المتحف والأسئلة ورسائل النجوم. نص الرسالة الرسمي محفوظ كاملاً ويظهر بعنوان «من مهدي إلى اسوقة ♡».
